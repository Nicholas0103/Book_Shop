## 📌 Project Overview

**The Bookish Clue** is a responsive, multi-page web application designed for a local indie mystery and detective bookstore. Stepping away from generic e-commerce designs, the website embraces a **Vintage Sherlock / British Detective** aesthetic featuring warm parchment tones, deep forest green accents, and subtle golden highlights. 

The application delivers an interactive shopping experience featuring dynamic category filtering, custom interactive components, and client-side form validation.

---

## 🎨 Design & Aesthetic

* **Theme:** Vintage Sherlock / Cozy British Mystery
* **Color Palette:**
  * Primary: English Forest Green (`#1A4332`)
  * Background: Warm Parchment (`#FDF8F0`)
  * Accent: Amber Gold (`#D4AF37`)
  * Text: Deep Charcoal (`#2B2B2B`)
* **Typography:** Classic Serif for titles (`Playfair Display` / `Georgia`) paired with clean Sans-Serif for body readability (`Inter`).

---

## 🗂️ Web Architecture & Pages

The website consists of 4 interconnected pages:

1. **`index.html` (Home Page):**  
   Hero banner introducing the bookstore, "Top Suspects" featured book section, and quick-access category teasers.
2. **`catalog.html` (Case Files & Catalog Page):**  
   Interactive book gallery displaying the store's full collection rendered dynamically from a JavaScript dataset (`books.js`).
3. **`about.html` (Investigation Team / About Us):**  
   Fictional backstory of the bookstore alongside structured "Investigator Dossiers" introducing the project's development team.
4. **`contact.html` (Tip Line / Contact Page):**  
   Case submission form with client-side JavaScript input validation and dynamic success alerts.
